# UI Contract: Setup Wizard Tabs

Route: `/setup`. Element ids are unchanged from today; only the tab that hosts them moves. Tests and any consumer select by these ids.

## Tab order

| # | Tab | Localization key |
|---|-----|------------------|
| 0 | Organisation Settings | `Setup_Tab_OrganisationSettings` (existing) |
| 1 | Accounting | `Setup_Tab_Accounting` (new) |
| 2 | Chart of Accounts | `Setup_Tab_ChartOfAccounts` |
| 3 | Opening Balances | `Setup_Tab_OpeningBalances` |
| 4 | Committee | `Setup_Tab_Committee` |
| 5 | Review | `Setup_Tab_Review` |

`#btn-next` appears on tabs 0 to 4. `#btn-finish` appears on tab 5 only.

## Field ids by tab

| Tab | Ids |
|-----|-----|
| Organisation Settings | `orgName`, `themeSelect`, `renewalMonth`, `auditRetentionYears` |
| Accounting | `setup-currency`, `setup-fy-start-month`, `setup-fy-start-day`, `setup-inception-date`, `annualFee`, `attendanceFee`, `taxApplicable`, and while tax is on: `taxRate`, `taxEntryMode`, `annualFeeTaxCode`, `attendanceFeeTaxCode` |

No id appears on both tabs. The wizard contains no `languageSelect` and no `seedData` control.
